About / Data Coverage

Commercial-use data sources included

United States weather: Federally published alerts (watches, warnings, advisories).

Canada weather: Federally published Canadian alerts where licensing allows redistribution.

USGS: Global earthquake data (last 30 days; includes Asia, Australia, Europe, Africa, and Americas).

Tsunami bulletins: Public tsunami warning center products.

NASA EONET: Public global event feeds used for cyclone and wildfire tracking pages.

Grid forecasts: Location-based future forecast periods on the Weather page.

Regional coverage summary

United States: Weather alerts + earthquakes.

Canada: Weather alerts + earthquakes.

Asia / Australia / Europe / Africa / South America: Earthquake data now; weather alerts added only when clear free commercial licensing is confirmed.

Why some weather providers are not included yet

Some regional weather APIs require paid commercial plans or separate written licensing agreements. This app only includes sources with clearly documented free commercial reuse rights.

Polling cadence

USGS (Earthquakes & Tsunamis page): scheduled every 5 minutes for near-real-time updates.

All other API sources: scheduled every 30 minutes.

Software updates

The Windows installer checks GitHub Releases for a newer version (same pattern as RootRecord Business Manager). You get a prompt to download; after download, another prompt to restart and finish installing.
